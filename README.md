## Overview
A turn-based roleplaying game where you play as a Carolianian freshie, on the mission to retrieve a mystical item lost in the dean's office called a diploma, rumored to unlock the ancient gates of the employment office

## Tech Stack
| Category | Tool / Language | Purpose |
|---|---|---|
| Engine | Godot Engine 4.x | Core game engine |
| Scripting | GDScript | Primary gameplay logic, turn-based state machines |
| Scripting (optional) | C# | Alternative scripting for stronger typing |
| Scripting (optional) | GDExtension (C++/Rust) | Performance-critical code or reusing existing libraries |
| Sprite Art | Aseprite / Piskel | Pixel art and sprite creation |
| Level Design | Tiled / Godot TileMap | Map and level design |
| Audio | Audacity | Sound editing |
| Audio (SFX) | Bfxr / sfxr | Retro sound effect generation |
| 3D/Cutscenes | Blender | Optional 3D assets or cutscenes |
| Data | JSON / Godot Resource (.tres) | Dialogue trees, item data, quest states |
| Save System | Godot ConfigFile / custom serialization | Save/load game state |
| Version Control | Git + GitHub | Source control |
| Backend (optional) | Godot networking (ENet/WebSocket) | Multiplayer, leaderboards |
| Backend (optional) | Firebase / Node.js + Express | Player stats, online features |
