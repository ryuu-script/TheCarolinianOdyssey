## Overview
A turn-based roleplaying game where you play as a Carolinian freshie, on the mission to retrieve a mystical item lost in the dean's office called a diploma, rumored to unlock the ancient gates of the employment office.

## Tech Stack
| Category | Tool / Language | Purpose |
|---|---|---|
| Engine | Godot Engine 4.x | Core game engine |
| Scripting | GDScript | Gameplay logic, turn-based state machines |
| Sprite Art | Aseprite / Piskel | Pixel art and sprite creation |
| Level Design | Godot TileMap | Map and level design |
| Audio | Audacity | Sound editing |
| Audio (SFX) | Bfxr / sfxr | Retro sound effect generation |
| Data | JSON / Godot Resource (.tres) | Dialogue trees, item data, quest states |
| Save System | Godot ConfigFile | Save/load game state |
| Version Control | Git + GitHub | Source control |

## Development Instructions
1. **Clone the repository** to your desired local path:
```
   git clone https://github.com/ryuu-script/TheCarolinianOdyssey.git
```
2. **Open the project folder** in your preferred IDE or code editor (e.g. VS Code).
3. **Create a new branch** for your changes before editing:
```
   git checkout -b feature/your-feature-name
```
4. **Make your changes**, then commit and push your branch:
```
   git add .
   git commit -m "Describe your changes here"
   git push origin feature/your-feature-name
```
5. **Open a pull request** on GitHub for review before merging into the main branch.
